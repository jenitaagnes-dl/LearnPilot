## 🧠 What is LearnPilot?

LearnPilot AI transforms textbooks, PDFs and educational material into
structured, interactive and personalized learning experiences.

Instead of simply reading and moving on, LearnPilot creates a continuous
learning loop:

**Upload → Generate → Learn → Assess → Analyze → Personalize**
